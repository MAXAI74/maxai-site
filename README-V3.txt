MAXAI SITE V3
================

Готовая статическая версия сайта.

Содержимое:
- 60 существующих хроник перенесены без изменения URL.
- Обложки оптимизированы в WebP до 1400x1400 для быстрой загрузки сайта.
- Главная автоматически построена вокруг последней хроники, присутствующей в предоставленном архиве: «Разные» (23.07.2026).
- Хроники: визуальная сетка, поиск, фильтр по году.
- Страницы треков: новая обложечная подача + сохранённые тексты и смысловые паспорта.
- Мобильное меню, share-кнопка, плавные появления с учётом prefers-reduced-motion.
- Исправлены битые ссылки на обложки у последних релизов и отсутствующий src/site.js.

ДЕПЛОЙ НА VERCEL
-----------------
Загрузи содержимое папки MAXAI-site-v3 как статический сайт. Build command не требуется.

ВАЖНО
------
Исходный архив заканчивается треком «Разные» (23.07.2026). Более поздние релизы в v3 намеренно не выдумывались и не добавлялись.

Файл src/tracks.json содержит центральный список метаданных всех хроник и может использоваться для дальнейшей автоматизации.
